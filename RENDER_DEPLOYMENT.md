# Deploying to Render

This guide provides step-by-step instructions for deploying the Marketing Post Scheduler application to Render.

## Prerequisites

Before deploying, ensure you have:

1. A [Render account](https://render.com)
2. Your MongoDB Atlas connection details:
   - Username
   - Password
   - Cluster address
   - Application name
3. Cloudinary account details (for image uploads):
   - Cloud name
   - API key
   - API secret

## Deployment Steps

### 1. Fork or Clone the Repository

Make sure your code is in a Git repository that Render can access (GitHub, GitLab, etc.).

### 2. Create a Blueprint Instance

1. Log in to your Render dashboard
2. Click on "New" and select "Blueprint"
3. Connect your repository
4. Render will automatically detect the `render.yaml` file and create the services

### 3. Configure Environment Variables

After the Blueprint creates your services, you'll need to set up the following environment variables in the backend service:

- `MONGO_USERNAME`: Your MongoDB Atlas username
- `MONGO_PASSWORD`: Your MongoDB Atlas password
- `MONGO_CLUSTER`: Your MongoDB Atlas cluster address
- `MONGO_APP_NAME`: Your MongoDB Atlas application name
- `CLOUDINARY_CLOUD_NAME`: Your Cloudinary cloud name
- `CLOUDINARY_API_KEY`: Your Cloudinary API key
- `CLOUDINARY_API_SECRET`: Your Cloudinary API secret

The `JWT_SECRET` will be automatically generated by Render, and the `FRONTEND_URL` will be automatically set based on your frontend service URL.

### 4. MongoDB Atlas Configuration

Make sure to:

1. Add your Render IP addresses to the MongoDB Atlas IP access list
2. Use a strong password for your MongoDB Atlas database
3. Ensure your database user has the appropriate permissions

### 5. Deploy the Services

1. Once environment variables are configured, click "Manual Deploy" and select "Deploy latest commit"
2. Render will build and deploy both the frontend and backend services

### 6. Access Your Application

After successful deployment:

- Your frontend will be available at the URL provided by Render for the frontend service
- Your backend API will be available at the URL provided by Render for the backend service

## Troubleshooting

- If you encounter build errors, check the build logs in the Render dashboard
- For runtime errors, check the service logs
- Ensure all environment variables are correctly set
- Verify MongoDB Atlas network access settings allow connections from Render's IP addresses

## Local Development After Deployment

When developing locally after deployment:

1. Use the `.env.local` file for frontend development with:

   ```env
   REACT_APP_API_URL=http://localhost:3002
   ```

2. Use the `.env` file for backend development with your local MongoDB settings
